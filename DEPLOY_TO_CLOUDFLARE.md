# Deploy Night to Cloudflare

Use Cloudflare's official one-click deployment flow to deploy a Night demo on Cloudflare Python Workers.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/22552/all-night/tree/main/deploy/cloudflare-night)

The button opens Cloudflare's deployment page, where you can sign in, choose names, and deploy the self-contained template from `deploy/cloudflare-night`.

For implementation details and local-development instructions, see [`deploy/cloudflare-night/README.md`](deploy/cloudflare-night/README.md).
